# 第二版：局域网在线房间

用户已确定版本顺序：先完成单人对战电脑，第二版增加多人局域网在线房间。本文件记录后续实现范围；当前版本尚未提供房间服务。

## 已保留的复用边界

- `createGame({ players, seed })` 创建牌局，不依赖 DOM、网络或浏览器存储。
- `applyAction(state, actorId, action)` 返回新状态，原状态不变。支持 `hit`、`stay`、`target`、`nextRound`。
- `currentActor(state)` 包括特殊牌目标选择，明确当前有权操作的席位。
- `publicView(state)` 隐藏牌堆顺序、随机数状态、弃牌内容和内部任务队列。电脑已经仅通过此视图决策。
- 状态包含版本号 `revision`，连锁处理队列可序列化，便于服务端保存和断线恢复。

## 第二版实施顺序

1. 增加房间服务与持久化，服务端唯一持有完整状态并运行规则与电脑；网页只接受公开视图。将现有界面中使用的牌堆计数改为公开字段。
2. 增加创建／加入房间、房间码、昵称、准备、开始、电脑添加和移除，支持真人与电脑混合的 3～6 人桌。
3. 用随机席位令牌标识玩家，服务端保存哈希。每次操作包含操作 ID 和预期 `revision`，校验身份、去重并拒绝过期状态。
4. 推送公开状态与在线状态，支持断线重连、刷新恢复、服务重启恢复；所有真人离线时暂停电脑。明确房主转移与离线席位处理。
5. 提供局域网地址／房间邀请链接，默认独立端口；同一服务同时提供网页和联机接口。
6. 增加多客户端集成测试：越权拒绝、重复动作、重连、特殊牌目标、并发操作、电脑暂停恢复、完整对局。

本机单人模式继续保留；在线牌局不采用客户端上传的完整状态作为真相，也不直接信任浏览器存档。
