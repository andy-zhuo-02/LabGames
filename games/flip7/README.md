# 七连翻 · Flip 7

第一版为单人对战电脑：一位真人与 2～5 位电脑组成 3～6 人牌桌。中文界面、原版卡面、完整基础规则，运行时无需联网，也不需要安装第三方依赖。

## 启动

需要 Node.js 22 或更新版本。在仓库根目录运行：

```bash
./games/flip7/start.sh
```

打开 **http://localhost:3007**。默认仅监听本机，与扑克的 8765、璀璨宝石的 3000 端口互不冲突。脚本会自动识别本工作站的 Codex 内置 Node 环境；其他机器安装标准 Node.js 即可。

```bash
PORT=3017 ./games/flip7/start.sh  # 自定义端口
./games/flip7/start.sh --dev     # 修改服务文件后自动重启；网页文件修改后刷新即可
./games/flip7/start.sh --test    # 规则与服务测试
```

也可以进入此目录运行 `npm start`、`npm test` 或 `npm run check`。不需要 `npm install` 或构建。按 Ctrl+C 停止服务。

## 玩法与功能

- 首页设置昵称和电脑人数。电脑有稳健、均衡、冒险三种策略，不读取牌堆顺序。
- 开局每人发一张，之后轮流选择「再翻一张」或「收手」。相同数字重复出现则爆牌，本轮为 0 分；第二次机会能抵消一次重复。
- 七张不同数字（含 0）触发七连翻，额外 +15 分，立即结算所有玩家。
- 冻结、连翻三张、第二次机会、五种加分牌与 ×2 倍率均已实现；特殊牌可选择有效目标。
- 达到 200 分后在轮末比较总分。最高分并列时，所有玩家继续加赛。
- 自动计分、积分榜、逐轮记录、最近 100 条牌桌动态；电脑速度切换、可选音效、手机布局。
- 22 种原版牌面、可点击放大查看的卡牌图鉴；首页、牌桌与弹窗统一采用原版的奶油黄、靛蓝、亮黄和珊瑚红配色。
- 焦点不在按钮或输入框时，可按空格翻牌、`S` 收手。打开说明或离开页面时，电脑暂停行动。

规则边界与来源见 [docs/RULES.md](docs/RULES.md)。

## 存档

每次有效行动自动写入当前浏览器的 `localStorage`；刷新后直接续局，包含待处理的特殊牌。没有服务器数据库。请在同一浏览器、同一主机地址和端口下访问，并避免用多个标签页同时操作同一存档。更换端口、清理站点数据或使用另一浏览器不会共享进度。

存档缺失或损坏时返回首页；浏览器禁止本地存储时会提示，当前页面仍可游玩。开始新局会替换旧局，未结束的对局需在页面内确认。

## 结构与验证

```text
src/game.js            纯规则引擎、公开视图与存档校验
src/bot.js             仅基于公开视图的电脑决策
web/                   原生 ES 模块、HTML、CSS；不加载外部素材
web/art/               本地保存的原版卡牌插图和标志
web/card-art.js        原始插图中的单张卡牌视口映射
server.mjs             Node 原生静态服务器，明确限定可访问文件
tests/game.test.mjs    固定牌序边界测试与 300 局完整模拟
tests/server.test.mjs  HTTP 页面、模块、牌面完整性与访问范围测试
```

28 项测试覆盖牌组分布、回合顺序、爆牌、护盾、特殊牌连锁、计分、平局加赛、洗牌及存档。300 局模拟覆盖 3～6 人桌，在每一步校验全部 94 张牌不丢失、不重复，并序列化后继续游戏。另已在浏览器完成一局 9 轮对局，并验证特殊牌目标选择、逐轮记录、刷新恢复和手机布局。

## 版本计划

- **v0.1：单人对战电脑（当前版本）。** 每个浏览器独立运行，尚无多人房间。
- **v0.2：多人局域网在线房间。** 复用现有规则引擎，增加服务端权威状态、房间码、真人与电脑混合席位、身份与重连恢复。具体拆分见 [docs/MULTIPLAYER.md](docs/MULTIPLAYER.md)。
