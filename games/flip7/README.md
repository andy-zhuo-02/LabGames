# 七连翻 · Flip 7

支持单人对战电脑和多人局域网房间：3～6 人同桌，真人与电脑可混合。中文界面、原版卡面、完整基础规则，运行时无需联网，也不需要安装第三方依赖。

## 启动

需要 Node.js 22 或更新版本。在仓库根目录运行：

```bash
./games/flip7/start.sh
```

打开 **http://localhost:3007**。默认监听局域网（`0.0.0.0`），与扑克的 8765、璀璨宝石的 3000 端口互不冲突。脚本会自动识别本工作站的 Codex 内置 Node 环境；其他机器安装标准 Node.js 即可。

```bash
PORT=3017 ./games/flip7/start.sh  # 自定义端口
HOST=127.0.0.1 ./games/flip7/start.sh # 仅本机访问
./games/flip7/start.sh --dev     # 修改服务文件后自动重启；网页文件修改后刷新即可
./games/flip7/start.sh --test    # 规则与服务测试
```

也可以进入此目录运行 `npm start`、`npm test` 或 `npm run check`。不需要 `npm install` 或构建。按 Ctrl+C 停止服务。

## 局域网联机

首页点击「局域网联机」创建房间，在大厅点击「邀请朋友」获得局域网地址。朋友连接同一网络，打开链接或输入房间码加入；至少 3 个席位，人数不足时添加电脑。真人准备后由房主开局。每次翻牌／收手及特殊牌选目标限时 10 秒，超时自动收手或代选目标；翻出「连翻三张」和选定目标时全桌即时提醒。支持自动重连、刷新续局、离线电脑托管、房主接任和服务器重启恢复。详见 [联机说明](docs/MULTIPLAYER.md)。

房主建房时可勾选「开启记牌器」（默认关闭），也可在准备大厅直接开启或关闭。整局结束后点击「再来一局」返回准备大厅即可调整，无需重建房间；修改后其他真人需重新准备，每局进行中保持不变。开启后全员在牌桌顶部点击「记牌器」，查看全部 22 种牌的剩余张数与全套张数；自己的数字牌用黄色标记，已无剩余的牌会淡化。统计随翻牌、特殊牌和洗牌实时更新；房间设置在重连、再开一局、房主接任及服务器重启后保留。

联机页面底部支持全桌弹幕：输入短句或点击快捷喊话，同房间在线玩家实时看到带昵称的飘屏消息。每条最多 40 字，每人每 2 秒一条；显示开关仅影响自己并记住偏好。弹幕不影响行动倒计时，刷新或重连不补播旧消息。

## 玩法与功能

- 首页设置昵称和电脑人数。电脑有稳健、均衡、冒险三种策略，不读取牌堆顺序。
- 每轮开场按座位顺序，由玩家点击「翻开第一张」，再进入轮流选择「再翻一张」或「收手」的阶段。开场特殊牌优先处理，被冻结或爆牌的席位跳过；联机开场同样限时 10 秒，超时自动翻牌。相同数字重复出现则爆牌，本轮为 0 分；第二次机会能抵消一次重复。
- 新对局和弃牌重新洗入牌堆时显示洗牌动画；整局结束后播放冠军庆祝和彩纸动画，展示前三名领奖台和全员最终排行榜（总分、单轮最高、七连翻次数）。支持并列名次、逐轮得分和回看最后牌桌；减少动态效果的系统偏好会关闭动画。
- 七张不同数字（含 0）触发七连翻，额外 +15 分，立即结算所有玩家。全桌显示实际七张牌展开、奖励与彩纸庆祝；若同时结束整局，也会显示最终赢家。
- 七连翻庆祝需所有真人点击「为ta鼓掌」后才会全桌收起，电脑自动鼓掌。显示已鼓掌人数和每个席位的状态；完成前不能进入下一轮或再开一局。刷新、重连和服务器重启保留进度，离线或托管的真人仍需回来确认。单人模式同样需要自己点击鼓掌。
- 达成七连翻的玩家会在积分榜和最终排行榜获得金色「7」勋章，展示本局累计次数。新成就播放勋章入场、流光和星光动画；换轮、重连后保留勋章，再开一局清零。
- 冻结、连翻三张、第二次机会、五种加分牌与 ×2 倍率均已实现；特殊牌可选择有效目标。
- 达到 200 分后在轮末比较总分。最高分并列时，所有玩家继续加赛。
- 自动计分、积分榜、逐轮记录、最近 100 条牌桌动态；电脑速度切换、可选音效、手机布局。
- 22 种原版牌面、可点击放大查看的卡牌图鉴；首页、牌桌与弹窗统一采用原版的奶油黄、靛蓝、亮黄和珊瑚红配色。
- 焦点不在按钮或输入框时，可按空格翻牌、`S` 收手。单人模式打开说明或离开页面时，电脑暂停行动；联机模式由服务器继续推进，所有真人离线才暂停电脑。

规则边界与来源见 [docs/RULES.md](docs/RULES.md)。

## 存档

**单人模式：** 每次有效行动自动写入当前浏览器的 `localStorage`；刷新后直接续局，包含待处理的特殊牌。请在同一浏览器、同一主机地址和端口下访问，并避免用多个标签页同时操作同一存档。更换端口、清理站点数据或使用另一浏览器不会共享进度。

存档缺失或损坏时返回首页；浏览器禁止本地存储时会提示，当前页面仍可游玩。开始新局会替换旧局，未结束的对局需在页面内确认。

**联机模式：** 牌局和席位保存在 `data/rooms.json`，浏览器仅保存自己的房间身份，单人进度不会被覆盖。重启服务后可继续；默认在启动时忽略超过 7 天未变更的房间。可用 `FLIP7_DATA_FILE` 自定义存档路径。

## 结构与验证

```text
src/game.js            纯规则引擎、公开视图与存档校验
src/bot.js             仅基于公开视图的电脑决策
web/                   原生 ES 模块、HTML、CSS；不加载外部素材
web/art/               本地保存的原版卡牌插图和标志
web/card-art.js        原始插图中的单张卡牌视口映射
src/rooms.js          房间权限、持久化、去重、在线状态与服务端电脑
src/applause.js       七连翻全员鼓掌回执与进度
web/network.js        HTTP 操作与 SSE 重连
web/danmaku.js        弹幕发送、显示开关与不打断输入的飘屏
server.mjs             Node 原生 HTTP / SSE 服务，明确限定可访问文件
tests/game.test.mjs    固定牌序边界测试与 300 局完整模拟
tests/server.test.mjs  HTTP 页面、模块、牌面完整性与访问范围测试
```

73 项测试覆盖牌组分布、手动开场、回合顺序、爆牌、护盾、特殊牌连锁、计分、平局加赛、洗牌及存档，以及排行榜并列名次、动画事件去重和记牌器开关、统计、同步与恢复。300 局模拟覆盖 3～6 人桌，在每一步校验全部 94 张牌不丢失、不重复，并序列化后继续游戏。浏览器验证覆盖重新洗牌、冠军庆祝、六人排行榜、手机布局及结算回看。弹幕测试覆盖房间隔离、身份、限频、重试去重、SSE 兼容与不影响行动时限。鼓掌测试覆盖全员门槛、同时点击、刷新与重启恢复、离线及托管真人、三联翻触发和最终赢家；双客户端浏览器验证进度同步、手机显示及全员完成后共同关闭。

联机测试另覆盖 4 局完整多人对局、三客户端 HTTP/SSE 同步、权限、并发去重、掉线处理、持久化及重启恢复。
