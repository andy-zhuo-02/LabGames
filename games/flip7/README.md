# 七连翻 · Flip 7

[← 返回 LabGames 游戏总览](../../README.md) · [联机说明](docs/MULTIPLAYER.md) · [规则说明](docs/RULES.md)

支持单人对战电脑与 3～6 人局域网房间。原版卡面、中文牌桌、自动计分与存档；翻到七张不同数字可获得额外 15 分奖励，向 200 分终点冲刺。

## 统一安装与启动

与其他两个游戏共用 **Node.js 22.13+（推荐 24）和 npm**。在仓库根目录执行：

```bash
npm install                    # 首次安装全部游戏依赖
npm start -- flip7             # 启动七连翻
npm run dev -- flip7           # 开发模式
```

本机访问 [http://localhost:3007](http://localhost:3007)。默认允许局域网连接，终端会显示朋友可访问的地址。按 `Ctrl+C` 停止。所有资源均在本地，电脑策略不需要 API Key。

七连翻本身继续使用 Node 内置模块和原生网页，无第三方运行依赖及编译步骤。根目录安装负责准备整个仓库，之后切换游戏无需再配置环境。在游戏目录直接运行 `npm start` 或 `node server.mjs` 也可用。

| 配置 | 默认值 | 作用 |
| --- | --- | --- |
| `FLIP7_PORT` | `3007` | 统一启动器中的服务端口 |
| `PORT` | `3007` | 单独启动时也可使用 |
| `HOST` | `0.0.0.0` | 设为 `127.0.0.1` 时仅本机 |
| `FLIP7_DATA_FILE` | `data/rooms.json` | 联机存档，建议自定义时使用绝对路径 |

旧 `./games/flip7/start.sh` 仍可用，现转发到 npm；`--dev` 和 `--test` 分别进入开发模式和测试。

## 与朋友联机

1. 首页点击「局域网联机」，输入昵称并创建房间。房主可选择是否开启记牌器。
2. 在大厅点击「邀请朋友」，分享局域网链接，或让朋友输入房间码加入。
3. 至少 3 个席位，人数不足时添加电脑。全体真人准备后由房主开局。
4. 每轮开场由大家依次翻第一张；联机每次行动最多 10 秒，超时由服务器代操作。

牌桌支持全桌弹幕、三联翻即时提醒、洗牌动画、冠军排行榜与七连翻勋章。七连翻庆祝需所有真人点击「为ta鼓掌」后收起，电脑自动鼓掌，刷新或重连保留进度。

记牌器由全房间共享开关，各玩家独立展开面板。整局结束后，房主点击「再来一局」返回准备大厅，即可开启或关闭记牌器，无需重建房间；修改后其他真人需重新准备。更多身份、托管、房主接任和协议说明见 [联机文档](docs/MULTIPLAYER.md)。

## 存档与备份

**单人模式**：进度保存在当前浏览器的 `localStorage`，每次有效操作自动保存。用同一浏览器、相同主机地址和端口打开即可续局。

**联机模式**：服务器将房间、席位、牌局和鼓掌进度保存到 `games/flip7/data/rooms.json`；浏览器保存自己的席位身份。加入联机房间不会覆盖单人存档。

- 刷新与重连会恢复原座位；更换浏览器、地址或清除站点数据后，原身份不会自动迁移。
- 服务器重启后可恢复牌局，启动时忽略超过 7 天未变更的房间。
- 备份前停止服务，再复制 `data/rooms.json` 或自定义存档文件。
- 同一存档文件只供一个服务器使用，多实例需要分别设置端口与 `FLIP7_DATA_FILE`。
- `data/` 已被 Git 忽略。损坏存档会阻止启动并报告错误，不会自动覆盖。

## 开发与检查

仓库根目录：

```bash
./games/flip7/start.sh --test
```

或在游戏目录中执行：

```bash
npm test         # 规则、模拟、房间与 HTTP/SSE 测试
npm run check    # JavaScript 语法检查与完整测试
```

测试覆盖牌组、特殊牌连锁、计分、300 局完整模拟、多人状态一致性、行动时限、弹幕、记牌器设置、全员鼓掌及持久化恢复。无需安装测试框架。

修改 `web/` 中的页面文件后刷新浏览器即可；修改服务端后重启，或使用 `--dev` 自动重启。

```text
src/game.js        纯规则引擎、公开视图与存档校验
src/bot.js         基于公开信息的电脑决策
src/rooms.js       房间、权限、持久化、计时与同步
src/card-tracker.js 记牌统计
src/applause.js    全员鼓掌状态
web/               网页、原版卡面、联机与动画
server.mjs         HTTP 与 SSE 服务
tests/             规则、房间与接口测试
```

## 常见问题

- **找不到 Node.js：** 安装 22.13 或更新版本；检查 `node --version`。
- **端口已占用：** 先确认是否已有服务运行；需要新实例时设置 `PORT`，并为其指定独立存档。
- **朋友连不上：** 保持默认 `HOST=0.0.0.0`，分享主机局域网地址，确保同一网络及防火墙允许对应端口。
- **鼓掌庆祝没有消失：** 面板会列出待鼓掌的玩家。离线或托管的真人仍需重连点击确认。
- **改不了记牌器：** 只有房主可在准备大厅调整，当前整局结束后先点击「再来一局」。
