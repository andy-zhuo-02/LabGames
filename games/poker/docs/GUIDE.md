## 浏览器牌桌

「轻松练手」「认真过招」「挑战一下」提供不同电脑组合，也可以自行挑选电脑。支持 2～6 个席位。自己的底牌默认可见，顶部「隐私」可在本机遮挡；鼠标移入、触屏按住或键盘按住空格暂时查看。正常摊牌时其他玩家仍能看到按规则公开的牌。

翻牌前、翻牌、转牌、河牌依次下注。「加到 100」表示本轮总下注达到 100，按钮附近显示还需投入多少。用自己的两张牌和五张公共牌选出最佳五张，也可以完全使用公共牌。A 可用于 A–2–3–4–5，花色不分大小。

牌型从大到小：同花顺、四条、葫芦、同花、顺子、三条、两对、一对、高牌。同类牌型继续比较组成点数和踢脚牌；相同则平分，零头按位置分配。所有未弃牌的摊牌参与者都亮牌；若其他玩家均弃牌，最后一人直接获胜，无需亮牌。

右侧可查看桌边动态、逐手复盘和本桌筹码曲线。操作提示始终以当前牌桌的合法行动为准。

## 好友房

「和朋友玩」可创建或申请加入六位房间码对应的房间。主机和朋友连接同一网络，分享主机的局域网链接或二维码。房主审批申请；已开局时，新朋友等下一手开始参与，不查看当前底牌。空位可由电脑补齐。

所有参与者共同准备后开始，每手结束后共同确认下一手。思考时间可选 15、30、60、90、120 秒。超时或离线超过 12 秒时，自动选择免费过牌或弃牌，不替真人跟注。原房主长时间离线时由在线成员接任。

「暂时离席」保留筹码与座位，本手自动过牌/弃牌，下一手不发牌，回来后重新准备。「离开牌桌」让电脑接替座位。房主可以移出玩家，被移出者不能立即用原会话重新申请。

可保存「我的座位恢复码」。换浏览器或设备时，在「最近房间 / 找回原座位」填写房间码及恢复码；旧页面会退出，恢复码会更新。不要把恢复码发给其他人。

## 命令行与模拟

以下命令在 `games/poker/` 执行；依赖统一在仓库根目录安装。

```bash
node cli.mjs
node cli.mjs --bots tight loose --seed 42
node cli.mjs --simulate 1000 --hero-bot tight --bots random loose --seed 42
node cli.mjs --stack 1000 --small-blind 5 --big-blind 10
node cli.mjs --bots nit equity --equity-samples 256
node cli.mjs --history hands.jsonl
```

输入 `f` 弃牌、`x` 过牌、`c` 跟注、`r 100` 加到 100、`a` 全下、`q` 退出。日志包含牌堆和复现信息，不应作为公开房间信息分享。真人淘汰结束交互对战；模拟模式完成指定手数，整场结束后自动重新开桌。

| 策略 | 行为 |
| --- | --- |
| `random` | 随机选择合法动作 |
| `tight` / `loose` | 根据牌力、位置、跟注成本决策，后者更积极 |
| `nit` | 更严格挑选起手牌 |
| `calling_station` | 偏爱过牌跟注，弱牌遇高成本时弃牌 |
| `maniac` | 频繁大额下注，包含弱牌诈唬 |
| `push_fold` | 12 个大盲以内主要全下或弃牌，深筹码使用紧手策略 |
| `equity` | 抽样未知牌估计摊牌分池份额；不模拟对手范围或边池精确收益 |

电脑只接收不可变的公开观察与自己的底牌，不接收对手底牌、牌堆或种子。

## 八策略锦标赛与曲线

```bash
node tournament.mjs --seed 42 --output runs/new-match
node plot-tournament.mjs runs/new-match
```

持续对战至一位玩家持有全部筹码。可用 `--stack`、`--small-blind`、`--big-blind`、`--equity-samples` 配置。输出目录必须是新目录；中断保留已完成牌局并标记 `interrupted`。

输出 `stacks.csv`、`hands.jsonl`、`summary.json`，绘图生成 `chip-curves.svg` 与 `chip-curves-seat-N.svg`。无需 Matplotlib，浏览器可以直接打开 SVG；新工具不生成 PNG。旧示例仍在 `runs/all-bots-seed42/`，单场结果不代表策略长期排名。

## 源码

`src/engine.mjs` 为规则、比牌及牌桌，`src/bots.mjs` 为电脑策略，`src/browser-game.mjs` 为公开视图及结算说明，`src/rooms.mjs` 为房间状态，`src/storage.mjs` 为存档与迁移，`server.mjs` 提供 HTTP。网页在 `web/`，测试在 `tests/`。

规则采用移动庄家、固定盲注；暂未实现死庄、升盲赛制。牌桌引擎支持 2～9 人，浏览器入口限制 2～6 人。
