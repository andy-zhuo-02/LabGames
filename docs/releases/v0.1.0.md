步步为营首个发布版本，加入 LabGames 桌游合集。

## 新增内容

- 支持 2～4 人电脑对战、同屏对弈和局域网好友房；空位可由电脑补齐。
- 完整走子、跳子、侧跳、横竖放墙和通路校验，支持三人扩展玩法。
- 重绘深色桌面、木质棋盘、棋子和围墙，精简页面排版与文案。
- 建房可选择不限时或每步 10／20／30／60／120 秒；房主可在准备室调整，开局后固定。
- 最后 5 秒突出提示，超时自动走子；刷新、重连和服务重启保留当前截止时间。
- 提供标准／轻松电脑难度、本地人机悔棋、路线提示、操作记录和存档恢复。
- 接入统一 npm 启动器，默认端口为 3009。

## 运行

主机需要 Node.js 22.13+，推荐 Node.js 24。在项目根目录执行：

```bash
npm ci
npm start -- quoridor
```

主机打开 `http://localhost:3009`。同一 Wi-Fi／局域网的朋友使用主机显示的局域网地址，通过邀请链接或房间码加入。

已有房间升级后继续沿用不限时规则，房主可在准备室调整。运行存档和座位凭证不包含在源码发布中。
