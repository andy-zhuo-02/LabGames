# 仓库迁移记录

[返回 LabGames](../README.md)

LabGames 将独立游戏放在 `games/` 下维护。仓库只有根目录的一份 `.git`，各游戏目录是普通子目录，可以分别运行和开发。

## 2026-09-10：导入扑克与璀璨宝石

两个游戏通过 `git subtree add` 导入，未压缩原有提交历史。

| 游戏     | 导入的原提交                               | 原分支   |
| -------- | ------------------------------------------ | -------- |
| 德州扑克 | `ca37c91cd65a443b5578529473c73043d1c74e1b` | `master` |
| 璀璨宝石 | `125da363d38fd9d7855ff50c5f13c58fde5e7137` | `master` |

原标签按游戏名加前缀保留，例如扑克的 `v0.0.0` 对应 `poker/v0.0.0`。在仓库根目录运行 `git log --all --graph --oneline` 可查看历史；迁移前的提交仍保留原路径。

迁移时使用 SQLite 备份接口复制了本机已有的游戏数据库，并迁入比赛记录、依赖和构建产物。存档、依赖及构建输出不随 Git 分发；新克隆的仓库应按各游戏 README 安装和启动。

原独立目录保留，后续与 LabGames 目录之间不会自动同步代码或存档。继续旧牌局时，应停止原服务，使用对应游戏的原存档、访问地址和端口启动，再由原浏览器恢复身份。
